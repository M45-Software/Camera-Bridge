# Camera Bridge 0.3.0

- Prefer Canon SDK live-view capture, with automatic gphoto2 fallback for missing
  or unsupported runtimes, capture failures, and stalled cameras.
- Add Capture backend selection to Advanced settings: Automatic, Canon SDK, and
  gphoto2. Explicit choices use only the selected backend.
- Bundle the tested unmodified Linux x86-64 Canon runtime and its provenance notice.
  Debian packages are now `amd64`; users do not need to download the SDK.
- Preserve native JPEGs, automatic frame timing, on-demand operation, and camera
  cleanup when capture is stopped.

Hardware comparison on an EOS 7D Mark II measured 1024 × 576 at 29.65 FPS through
Canon SDK versus 14.50 FPS through gphoto2 after selecting a higher movie frame
rate. Both measurements used 20 seconds after warmup and found no identical
decoded frames. These results do not establish 60 FPS USB capture or higher
native resolution.
