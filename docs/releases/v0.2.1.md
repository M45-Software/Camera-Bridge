# Camera Bridge 0.2.1

- Make webcam availability and the tray start at graphical login by default, with
  independent, immediately saved options on the main window.
- Save settings automatically. Apply changes to running video only when requested,
  with a prominent close/reopen-apps dialog before reconnecting.
- Add Close window and confirm Quit from both the controls and tray menu.
- Add tray actions to keep the camera on, keep it off without removing the virtual
  webcam, or return to automatic app-driven control.
- Give the packaged launcher its own Camera Bridge desktop ID so stale launchers
  from older script installations cannot hide it.

Quit the old tray before upgrading, then reopen Camera Bridge. Login defaults take
effect on the next graphical sign-in; no logout is required to test the controls.
