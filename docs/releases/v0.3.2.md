# Camera Bridge 0.3.2

- Treat a powered-off or disconnected camera, including at login, as a normal **Waiting for camera** state without warning notifications.
- Keep the virtual webcam available while waiting for a camera, without repeatedly cycling through capture startup.
- Preserve automatic recovery when a connected camera stops producing live-view frames.

Validated with 49 automated tests, Qt smoke checks, shell syntax checks, and Debian package construction.
