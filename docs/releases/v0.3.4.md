# Camera Bridge 0.3.4

- Keep Canon SDK live view on for the configured rest delay after the last video app closes. The default is 60 seconds. Reopening a video app during the delay resumes the same camera session.
- Show **Lost connection** in the virtual webcam feed after half a second without a complete frame during live capture. Video resumes automatically when frames return.

Verified with 51 automated tests and an EOS 7D Mark II live-view test.
