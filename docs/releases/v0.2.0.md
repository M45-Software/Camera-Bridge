# Camera Bridge 0.2.0

Camera Bridge turns compatible Canon cameras into a persistent Linux webcam,
with KDE tray controls and automatic capture when a video app opens the device.

- Plain-language status for camera connection, live view, and video activity.
- Automatic processing pause and a configurable 60-second camera rest delay.
- Native live-view size and camera frame timing, with compatibility overrides.
- Static status cards, a brief starting animation, and camera recovery guidance.
- Raw YUV420 output by default; experimental original-JPEG passthrough.
- Debian package and signed M45 Software APT installation and updates.

Targets Ubuntu/Kubuntu 24.04. Hardware testing has used an EOS 7D Mark II;
compatibility varies by camera and receiving app. Camera Bridge is independent
and is not affiliated with or endorsed by Canon.

Existing service/configuration identifiers and the `canon-webcam` command alias
are retained. See the README for migration from older script installations.
